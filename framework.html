CORE CAPABILITIES

四大核心能力领域

四个方向共同描述模型从感知到安全回应的能力链路，不设置固定权重。

01

情感共情

测评模型是否具备类似人类情感共情中的情绪敏感性、情绪线索识别和多模态情绪感知能力。

02

认知共情

测评模型能否理解人类为什么会有这种情绪，以及用户隐含的心理状态、意图、需求和处境。

03

共情关怀

测评模型能否把情绪感知和理解转化为关怀、支持、安抚、引导和关系修复等输出。

04

安全交互

测评模型在高风险、脆弱、依赖、危机或不确定情境中，能否保持安全、边界、非操控的原则。

EVALUATION PROCESS

测评流程

01
数据组织

按任务目标组织公开数据源、标准化资源与子任务视图，明确输入模态、样本量与可复核来源。

02
评测执行

在模态匹配后执行模型作答与任务评分，记录版本、日期、评委信息和异常信息，保证后续复核。

03
指标分析与使用

按任务类型解释指标方向和可比较范围，对外公开框架与结果，工具脚本按用途审核后提供。

数据来源→ 标准化资源→ 任务视图→ 模态匹配→ 模型作答→ 任务评分→ 结果记录
任务类型指标示例指标方向
分类Accuracy / F1 / Macro-F1越高越好
回归MAE / RMSE / CCCMAE/RMSE 越低越好，CCC 越高越好
选择题Accuracy / Pass@1越高越好
抽取Exact Match / F1越高越好
参考式生成ROUGE / BLEU / BERTScore越高越好
模型评委与偏好判断Pairwise Win Rate / Preference Score越高越好

结果记录最小字段：模型、任务、数据子集、输入模态、样本量、评测日期、主指标、评委信息、异常信息。框架评估的是模型在任务中的可观察行为，不宣称模型具备意识、主观情感或临床能力。

Cognitive Empathy
  • 情绪原因与对象推理

  • 支持策略选择
